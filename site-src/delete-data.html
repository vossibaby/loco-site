Loco / Data control

Delete Data

You control local projects and can disconnect the Google connection at any time.

Delete local project data

  1. Open Loco and go to Projects.
  2. Open the project menu and choose Delete Project.
  3. Confirm the deletion. Loco removes the project record and the app-owned managed media, renders, thumbnails, and upload journals for that project.

Disconnect Google / YouTube

  1. Open Loco’s Account area.
  2. Choose Disconnect Google or Sign out, then confirm.
  3. For an additional revocation, open your Google Account third-party connections and remove Loco.

Disconnecting Loco does not delete videos already uploaded to YouTube. To remove a YouTube video, use YouTube Studio or the YouTube app.

Request deletion help

If you cannot access the app, open a request in the Loco GitHub issue tracker with the title “Delete Data Request”. Do not include OAuth tokens, passwords, or private media. Tell us which local or Loco-held data you want removed and a safe way to respond. We will use the request only to process deletion.

Loco does not operate a separate user account database or a cloud media library. Most Loco project data exists only in the app’s local storage on your device.

Data on YouTube

Videos, playlists, thumbnails, and channel data already sent to YouTube are controlled by your YouTube account and YouTube’s own deletion tools. Loco cannot delete a YouTube video without an authorized request and an explicit user action.
